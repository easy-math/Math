          # 向量组及其线性组合

          # 简介

          向量组是一组向量的集合。用标量线性组合它们，可以生成一个新的向量集合（张成空间）。

          # 线性组合

          给定向量组 ，任意向量

          称为它们的线性组合。

          # 张成

          所有线性组合构成的集合称为该向量组的张成（span）。

          # 应用

          • 描述解空间。
          • 构造基。
