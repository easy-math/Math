            # 矩阵的初等变换

            # 简介

            矩阵的初等变换是对矩阵做“行（列）交换、倍乘、加倍”这三类最基本的操作，它们对应线性方程组的消元过程。

            # 三类初等变换

            1. 交换两行（列）。
            2. 某一行（列）乘以非零常数 。
            3. 某一行（列）加上另一行（列）的 倍。

            # 与线性方程组

            对增广矩阵 做初等行变换，不改变方程组的解集。

            # 初等矩阵

            对单位矩阵做一次初等变换得到的矩阵称为初等矩阵。左乘初等矩阵等价于对原矩阵做相应的行变换。

            # 应用

            • 高斯消元。
            • 求秩与求逆。
