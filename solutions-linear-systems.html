            # 线性方程组的解

            # 简介

            线性方程组 的解集由矩阵的秩决定，并可通过初等变换求出。

            # 判定

            • 无解：。
            • 唯一解：两秩相等且等于未知数个数 。
            • 无穷多解：两秩相等但小于 。

            # 解法思路

            将增广矩阵化为行阶梯形/行最简形，回代或直接读出解。

            # 齐次与非齐次

            齐次方程组总有零解；若秩小于 ，则有非零解。

            # 应用
