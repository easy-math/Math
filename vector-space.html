          # 向量空间

          # 简介

          向量空间是满足加法与数乘封闭的一类集合，是线性代数的基本对象。

          # 定义（概要）

          集合 在加法和数乘下满足封闭、交换、结合、分配等公理，则称为向量空间。

          # 子空间

          若 且在加法与数乘下仍封闭，则 是子空间。
