            # 矩阵的秩

            # 简介

            矩阵的秩（rank）是矩阵中线性无关行（或列）的最大个数。它刻画了线性方程组的独立约束数量。

            # 定义等价形式

            • 行秩 = 列秩。
            • 非零子式的最大阶数。
            • 化为行最简阶梯形矩阵后非零行数。

            有解当且仅当 。
