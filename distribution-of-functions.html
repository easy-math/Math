        # 随机变量函数的分布

        # 简介

        给定随机变量 ，函数 也是随机变量，其分布可由变量变换得到。

        # 思路

        • 单调函数用分布函数法。
        • 一般函数可用密度变换或分段处理。

        # 应用

        • 求线性变换后的分布。
        • 归一化处理。
